# MailCraft — מדריך בעברית

**דואר אלקטרוני מקומי ליוצרים** — לקוח דואר בקוד פתוח, שנבנה ב־Rust ומשתלב במשפחת ArtCraft.

MailCraft מספק ממשק דואר בן שלושה אזורים: תיקיות, רשימת הודעות וחלונית קריאה. אפשר להשיב, להשיב לכולם, להעביר הודעות, לסמן, לארכב, למחוק ולבצע שליחה וקבלה. היישום פועל מול שרת הדואר שלכם באמצעות IMAP ו־SMTP, וכן תומך ב־JMAP ובחשבונות Exchange Online.

ההודעות נשמרות במטמון מקומי כדי לאפשר חיפוש מהיר וקריאה גם ללא חיבור. הסיסמאות נשמרות במחסן האישורים של מערכת ההפעלה, ולא במסמכי MailCraft. תמונות חיצוניות בהודעות אינן נטענות ללא בחירתכם.

> **מצב שפה:** נכון לגרסת המקור שעליה מבוסס מדריך זה, עברית עדיין אינה רשומה כאחת משפות ממשק המשתמש. מסמך זה הוא מדריך בעברית ואינו משנה את שפת הממשק או את כיוון הפריסה. מידע על העבודה המתוכננת נמצא במאגר הפרויקט.

## למה MailCraft?

- **ממשק מוכר:** תיקיות, רשימת הודעות, חלונית קריאה וסרגל פקודות.
- **עבודה גם ללא רשת:** ההודעות שכבר סונכרנו זמינות לקריאה, ופעולות ממתינות לשליחה עם חידוש החיבור.
- **פרטיות:** תקשורת ישירה עם שרתי הדואר, הצפנת TLS והסתרת תמונות מרוחקות כברירת מחדל.
- **חיפוש מקומי:** סינון לפי שולח, נושא, הודעות שלא נקראו וקבצים מצורפים.
- **קבצים מצורפים:** תצוגות מקדימות ותמיכה בפתיחת קבצים ביישומי Craft מתאימים.
- **אוטומציה:** הפקודות שמפעיל הממשק זמינות גם דרך CLI עם מזהי פקודות קבועים.
- **רישוי פתוח:** MIT או Apache-2.0.

## יכולות עיקריות

| תחום | אפשרויות |
|---|---|
| חשבונות | IMAP/SMTP, ‏JMAP ו־Exchange Online, מספר חשבונות, גילוי הגדרות שרת וכניסה באמצעות OAuth |
| סנכרון | עדכון מצטבר, שמירת הודעות במטמון, הודעות חדשות, שחזור שינויים שבוצעו במצב לא מקוון |
| קריאה | קיבוץ שיחות, סימון הודעות שלא נקראו, דגלים, תצוגות מקדימות והדפסה ל־PDF |
| ארגון | תיקיות, מועדפים, כללים, קטגוריות, העברה, ארכיון, דואר זבל וסימון לקריאה מאוחרת |
| כתיבה | הודעה חדשה, תשובה, השב לכולם, העברה, טיוטות, חתימה, עיצוב טקסט וקבצים מצורפים |
| לוח שנה ואנשי קשר | תצוגת יום, שבוע וחודש, פגישות והזמנות, CalDAV ו־CardDAV |
| חיפוש | חיפוש בין תיקיות, ביטויים מדויקים, סינון לפי שולח, נושא וקובץ מצורף |

הגרסה כוללת תצוגת קבצים מצורפים, תמונות ותצוגות מקדימות, אולם אין להסיק מכך שכל תכונות הקבצים נתמכות במלואן. פערי המימוש מתועדים ב־[docs/gaps.md](docs/gaps.md).

## הפעלה מהירה

לאחר התקנת Rust ו־Cargo, אפשר לפתוח תיבת דואר לדוגמה ללא צורך בחשבון:

~~~bash
cargo run --release -p mailcraft -- --sample
~~~

האפשרות --sample פותחת תיבה מקומית לדוגמה. כדי להתחבר לחשבון אמיתי, מפעילים את היישום בלעדיה ומוסיפים חשבון ממסך הפתיחה או מההגדרות.

### עבודה משורת הפקודה

הסיסמה מתקבלת ממשתנה הסביבה MAILCRAFT_PASSWORD או מתבקשת בקלט; אין צורך לשמור אותה בקובץ:

~~~bash
cargo run -p mailcraft-cli -- add --email you@example.com
cargo run -p mailcraft-cli -- test
cargo run -p mailcraft-cli -- sync
cargo run -p mailcraft-cli -- list --limit 10
cargo run -p mailcraft-cli -- search "from:zoe has:attachment"
cargo run -p mailcraft-cli -- commands
~~~

לחשבון עם כתובות שרת ידועות ניתן לציין שרתי IMAP ו־SMTP במפורש, ולחשבון JMAP ניתן לציין את כתובת ה־session של הספק. מומלץ לבדוק תחילה את פלט פקודת העזרה לפני שינוי נתוני חשבון.

### הפעלה בדפדפן

גרסת הדפדפן תומכת בחשבונות JMAP. להרצה מקומית:

~~~bash
cd apps/mailcraft-web
trunk serve
~~~

לאחר מכן פותחים את כתובת השרת המקומי ש־Trunk מציג. למצב הדגמה יש להוסיף את הפרמטר ?sample לכתובת הנתמכת.

### היכן נשמר המידע?

- Windows: ‏%APPDATA%\MailCraft
- macOS: ‏~/Library/Application Support/MailCraft
- Linux: ‏~/.local/share/mailcraft

אפשר לשנות את ספריית הנתונים באמצעות --data DIR או משתנה הסביבה MAILCRAFT_DATA.

## איך הפרויקט בנוי?

MailCraft משתמש במספר שכבות Rust נפרדות:

- **model:** חשבונות, הודעות, חיפוש, תאריכים ונתוני שיחות.
- **mime / store / print:** פענוח ויצירת הודעות, מטמון מקומי והפקת PDF.
- **jmap:** חיבור לתקן JMAP בדסקטופ ובדפדפן.
- **net:** תקשורת שרתים, IMAP, ‏SMTP, ‏Microsoft Graph, ‏CalDAV ו־CardDAV.
- **engine:** מצב היישום ומרשם הפקודות, ללא קוד רשת.
- **ui-egui:** ממשק הגרפי המבוסס על egui.
- **apps:** יישום שולחן העבודה, CLI וגרסת הדפדפן.

מידע נוסף נמצא ב־[docs/architecture.md](docs/architecture.md). בדיקות הפרויקט מופעלות באמצעות:

~~~bash
cargo xtask ci
~~~
